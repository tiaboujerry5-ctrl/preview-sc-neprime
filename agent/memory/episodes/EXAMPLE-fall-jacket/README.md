# Worked example — the loop end to end

**Fictional.** Products, prices and sources are invented to show the shape of the
artifacts. Read it after `protocols/00-loop.md` to see how the pieces connect.

The request was five words: **"I need a jacket for fall."**

Watch what the framework does with that — it asks two questions, states four
assumptions, eliminates on gates, gets its top pick killed by the skeptic, and
learns one conditional preference it can only discover by *not* overwriting.
